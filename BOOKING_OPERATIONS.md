# Xerom Booking Operations

This guide is for Xerom staff. Website bookings and staff-created bookings use the same private Google Calendars.

## Calendars you will see

- XEROM — Regular Sim 01
- XEROM — Regular Sim 02
- XEROM — Regular Sim 03
- XEROM — Pro Sim 01
- XEROM — PS5 Lounge 01
- XEROM — PS5 Lounge 02
- XEROM — Booking Control

Keep every calendar private. Do not publish or share a public calendar link.

## View today’s bookings

1. Open Google Calendar.
2. Make sure all seven XEROM calendars are checked in the left sidebar.
3. Switch to Day or Schedule view.
4. Website bookings begin with an ID such as `XR-7K2FQ`.
5. Open an event to see the customer name, phone, service, duration, and booking total.

One group booking may create several events with the same booking ID. This is normal when more than one rig or lounge is reserved.

## Add a walk-in or telephone booking

1. Check the correct resource calendars for the whole session.
2. Create an event on each resource the customer needs.
3. Use the exact start and end time.
4. Put a useful title such as `WALK-IN | REGULAR | Customer name`.
5. Save the event as Busy.

Any Busy event blocks website availability automatically. You do not need to use a special title.

## Block one rig or lounge

Create a Busy event on that resource’s calendar for the unavailable period. Use a title such as `MAINTENANCE` or `UNAVAILABLE`. The website will stop offering that resource during the event.

## Block the entire venue

Create a Busy event on `XEROM — Booking Control`. Use the exact start and end time and a title such as `VENUE CLOSED` or `PRIVATE EVENT`. Every online resource will be unavailable during that period.

## Find a booking

1. Copy the booking ID the customer gives you.
2. Use Google Calendar search.
3. Search the full ID, including `XR-`.
4. Check every result. A multi-rig booking has several events with the same ID.

## Cancel a booking

1. Search the booking ID.
2. Confirm the customer and session time.
3. Delete every event carrying that booking ID.
4. Tell the customer on WhatsApp that the cancellation is complete.

Never delete only one event from a multi-resource booking unless the customer is intentionally reducing the booking and staff have confirmed the remaining resources.

## Change a booking

1. Search the booking ID and open every matching event.
2. Check that the new time is free on every required resource.
3. Move every matching event to the same new start/end time.
4. Confirm the change with the customer on WhatsApp.

## When something looks wrong

If a customer has a confirmation but events are missing or incomplete, search the booking ID first. Do not create replacements until you have checked every resource calendar. Record the ID, time, and affected calendars for the developer.
